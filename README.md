# たし算の筆算

小学算数の「たし算の筆算」を、くらいごとの操作に分けて練習する静的Webアプリです。

## レベル
- LEVEL 1：2けた＋2けた、くり上がりなし
- LEVEL 2：2けた＋2けた、一のくらいのくり上がりを見分ける（くり上がりなしも出題）
- LEVEL 3：2けた＋2けた、二つのくらいのくり上がりを見分ける（くり上がりなしも出題）
- LEVEL 4：3けた＋3けた

## 学習の流れ
LEVEL 1は「右から計算する → 答えを書く」。LEVEL 2以降は、毎回「くり上がりがある／なし」を判断してから答えを書きます。くり上がりがあるときは、たとえば 9＋4 を 13 と入力すると、1をくり上げ、3をそのくらいの答えに自動で分けて書きます。
児童が数字を入力して正誤を確かめ、正解した数字だけ筆算の盤面に反映されます。
3けたの問題では、4けたの答えになった場合の左はしのくり上がりにも対応しています。

## 構成
index.html：画面の骨組み
styles.css：タブレット向けの表示
app.js：レベル設定、問題生成、筆算データ、学習ステップ、記録

後からレベルを追加する場合は、基本的に LEVELS と generateProblem() に条件を追加します。
筆算の計算本体は createProblemModel()、学習手順は buildSteps() に分離しています。

## 今後の拡張
ナビキャラ、ナビアン、効果音、特訓モード、記録の詳細表示などは、筆算エンジンから分離して追加できる構成にしています。

外部APIやサーバーは使用せず、記録は端末の localStorage に保存します。
